## Catalog-quality limits

1. **Legacy names/classifications conflict with execution guidance**, as recorded in duplicate skips. Existing glutes-primary sled leg press, triceps-primary incline dumbbell press, the twist/glutes classification, and curl naming warrant a separate reviewed cleanup. No existing record was corrected here.
2. **Difficulty is null**, by explicit instruction. Unknown difficulty is currently eligible and does not establish suitability for beginners; technical metadata validation is not professional exercise or programming review.
3. **No deployed explicit movement-pattern metadata exists.** The current validator only enforces pattern coverage when all selected exercises have explicit patterns. The successful preview can select a rear-delt movement for shoulders without proving vertical-push coverage. No pattern labels were inferred or validation weakened to force success.
4. **Support equipment and location are incomplete metadata.** A bench, stable step, pull-up bar, safety rack or cable attachment can be required by instructions but absent from the single equipment label. Dumbbells/bodyweight compatibility is an algorithmic result, not proof that an arbitrary home setup has all supports.
5. **Plank is a timed hold**, while the current generator uses generic repetition prescriptions. The tested first preview selected Hanging Knee Raise, but future selection/configurations could expose the hold-versus-repetitions mismatch. Duration-specific programming remains a separate design/review issue.
6. **Missing media is intentional.** All 48 new rows use the existing COMING SOON fallback until actual GIFs are added to the same rows.
